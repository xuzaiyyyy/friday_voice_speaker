双链路 WebRTC 拉流控制台

方案1：启动时选择 LAN / WAN 配置

当前页面不再做运行时局域网 / 公网硬切。请在启动程序时通过 --lan-mode 或 --wan-mode 选择对应配置文件， 页面只负责发起 WebRTC 播放协商，这样更符合 ZLMediaKit 的全局 RTC 配置方式，也更稳定。

链路与协商地址

局域网测试时请先用 --lan-mode 启动程序，再通过设备局域网 IP 打开本页面； 公网测试时请用 --wan-mode 启动程序，并通过映射后的公网地址打开本页面。

推荐启动方式

  • 局域网 / 热点联调：./app --lan-mode
  • 公网穿透测试：./app --wan-mode
  • 也可以显式指定：./app --zlm-config ../config.lan.ini

音频按钮当前语义

  • 关闭：只请求视频，播放器保持静音
  • 开启：请求音频，并尝试取消静音播放
  • 如果后端没有音频轨，页面会提示“未收到音频轨”
